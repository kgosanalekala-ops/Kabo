# KABO SD-WAN — Conceptual Reference Brief

## Purpose
Connect distributed offices and cloud services using software-defined WAN overlays over suitable underlay connectivity.

## Reference components
- SD-WAN edge devices at headquarters and branches
- Underlay links: fibre, internet broadband, LTE/5G and/or MPLS, selected by location and SLA
- Authenticated/encrypted overlay connectivity and application-aware path selection
- Central orchestrator for configuration, assurance and policy
- Firewall, secure breakout and cloud access integrated by security design

## Design discovery
Provide site list, available last-mile services, application matrix, throughput, security policies, availability objectives and existing vendor contracts.

## Important limits
This is an illustrative architecture, not a complete network design, product certification, bill of materials, implementation plan or SLA. Hardware, subscriptions and configuration depend on detailed discovery and applicable OEM product availability.
