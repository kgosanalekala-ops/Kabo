# KABO Campus Network — Conceptual Reference Brief

## Purpose
Design a high-performance wired and wireless campus with resilient backbone connectivity and access policies.

## Reference layers
- Redundant core switching or collapsed core appropriate to the scale
- Aggregation/distribution where required
- Wired PoE access and fibre uplinks
- Enterprise Wi-Fi based on RF survey and device density
- Firewall and WAN edge; identity/NAC, network telemetry and segmentation

## Design discovery
Provide floor plans, buildings, cabling inventory, endpoint counts, Wi-Fi density and coverage targets, PoE requirements, uplink distances, security policy and available power.

## Important limits
This is a reference concept, not a site-specific network design or confirmed bill of materials. Detailed topology and OEM platform selection require engineering discovery.
